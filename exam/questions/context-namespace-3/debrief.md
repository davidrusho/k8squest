Every exam task names its context; the first command is `kubectl config use-context <name>`, copied exactly from the task. `kubectl config current-context` confirms it. A wrong context is the cheapest way to lose a whole task. After a passed check the context on cka1 was switched back for you and the answer file removed, so the kind tasks that follow are not sent to the kubeadm cluster. If you pressed Show solution instead, or stop without checking, run `kubectl config use-context` back yourself; opening this task again resets it.

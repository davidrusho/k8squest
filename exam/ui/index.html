    Exam environment

    This is a practice version of the CKA exam interface. The task panel is on the left; this area holds the environment.

    How to work

    • Open the Remote Desktop tab. Open a terminal there. You start on the base host, which has no kubectl.
    • Each task names the host to use: ssh cka1, ssh cka2 or ssh cka3. All three hosts use the same cluster.
    • Each task has its own namespace, exam-tNN. The task text gives it.
    • Documentation allowed: kubernetes.io/docs, as on the real exam.

    Differences from the real exam

    • Check grades the current task at once and shows the validator output. A pass is recorded either way.
    • Timer per task, 7.5 minutes (120 minutes / 16 tasks). A task's clock runs only while that task is shown and this page is visible. Time accumulates across visits.
    • You can keep working after the clock runs out. A pass after that is recorded as passed over time and does not count. Redo that task within 7.5 minutes in a later session.
    • Results are kept across sessions. End exam shows what counted and offers a new session with the missed tasks first.
    • The first time you open a task its broken environment is built. That can take up to a minute for some tasks.

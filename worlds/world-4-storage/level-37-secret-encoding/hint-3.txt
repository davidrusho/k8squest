✅ HINT 3: Complete Solution

Fix: Encode the username exactly once (Secret data values are the base64 of the plain value)

📝 In Secret:
```yaml
apiVersion: v1
kind: Secret
metadata:
  name: db-credentials
  namespace: k8squest
type: Opaque
data:
  username: YWRtaW4=  # ✅ base64 of "admin"
  password: c2VjcmV0cGFzczEyMw==  # ✅ base64 of "secretpass123"
```

🔧 How to encode:
```bash
echo -n "admin" | base64
# YWRtaW4=

echo -n "secretpass123" | base64
# c2VjcmV0cGFzczEyMw==
```

🚀 Apply:
```bash
kubectl delete -f broken.yaml
kubectl apply -f solution.yaml
# (a crash-looping pod only re-reads its Secret when its container restarts; deleting it
#  first, as above, avoids waiting out the restart back-off)
kubectl logs database-client -n k8squest
# Should show "Connected successfully!"
```

💡 Alternative: Use stringData for automatic encoding:
```yaml
apiVersion: v1
kind: Secret
stringData:  # No manual encoding needed!
  username: admin
  password: secretpass123
```

Remember: Secret "data" requires base64, "stringData" accepts plain text!

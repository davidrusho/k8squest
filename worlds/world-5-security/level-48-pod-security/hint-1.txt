# 💡 HINT 1-3: Pod Security Standards

## HINT 1: The Problem
```bash
kubectl get deployment,rs,pods -n k8squest   # Deployment 0/1, no Pods
kubectl describe rs -n k8squest              # look at Events
# Warning FailedCreate ... pods "secure-app-..." is forbidden:
#   violates PodSecurity "restricted:latest": allowPrivilegeEscalation != false ...
```

Namespace enforces "restricted" standard. Your Deployment's Pod template violates it.
Enforce mode checks Pods, not the Deployment, so the Deployment was accepted and the
rejection shows up on the ReplicaSet.

## HINT 2: Restricted Requirements

All of these MUST be set:
1. `runAsNonRoot: true`
2. `runAsUser: <non-zero>`
3. `allowPrivilegeEscalation: false`
4. `capabilities.drop: [ALL]`
5. `seccompProfile.type: RuntimeDefault`

## HINT 3: Solution

```yaml
# Deployment spec.template.spec
spec:
  securityContext:
    runAsNonRoot: true
    runAsUser: 1000
    seccompProfile:
      type: RuntimeDefault
  containers:
  - name: app
    securityContext:
      runAsNonRoot: true
      runAsUser: 1000
      allowPrivilegeEscalation: false
      capabilities:
        drop: [ALL]
```

Put these in the Deployment's `spec.template.spec`, apply, and run `./validate.sh`
